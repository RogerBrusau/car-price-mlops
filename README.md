## 📖 Introduction & Motivation
The genesis of this project stems from a personal need. While navigating the process of purchasing a second-hand car in Spain, I realized there was a significant lack of transparent, data-driven tools available on the internet to help buyers genuinely understand the current market value of a vehicle. 

To bridge this gap, I decided to build a comprehensive End-to-End (E2E) Machine Learning pipeline. By extracting and analyzing real market data from other vehicles, this tool aims to provide a reliable reference point, helping users gauge whether a car is overpriced, underpriced, or sitting fairly at market value.

## 🏗️ Project Architecture
This repository is not just a predictive model, but a complete **Data Engineering and MLOps system** designed for scalability and robustness. It is divided into two primary environments:

### 1. Data Ingestion & Processing (`/used_car_dataset`)
Built with a Medallion Architecture (Data Lake concept):
* **Asynchronous Scraping:** A custom-built, resilient scraper designed to bypass standard blocks, utilizing a SQLite queuing system to ensure no data loss during extraction.
* **Bronze Layer:** Storage of raw, unprocessed HTML files directly from the source.
* **Silver Layer:** Parsed and structured data stored in highly efficient `.parquet` formats.
* **Gold Layer:** The final, cleaned, deduplicated, and engineered dataset ready for Machine Learning consumption.

### 2. Machine Learning & Serving (`/NOUPROGRAMA`)
Instead of predicting a single absolute price, this project utilizes a `HistGradientBoostingRegressor` configured for **Quantile Regression**. 
By predicting the 10th, 50th, and 90th percentiles, the model outputs a realistic pricing bracket:
* **p10 (Lower Bound):** Fast-sale price / Trade-in value.
* **p50 (Median):** The standard fair market value.
* **p90 (Upper Bound):** Premium dealership pricing or vehicles in pristine condition.

## 📊 Dataset & Scope
* **Market:** Spanish second-hand vehicle market.
* **Timeframe:** Data was extracted during the **beginning of the year 2026**.
* **Volume:** The current model is trained on a refined dataset of approximately **15,000 to 20,000 unique car listings**.

### 🔄 Scalability & Continuous Scraping
This architecture was specifically designed with automation in mind. The ingestion pipeline can (and should) be deployed as a periodic cron-job (e.g., weekly or monthly) to continuously scrape new listings and update prices. 

**Future Scalability:** If someone wishes to fork this project, the YAML-based configuration allows for the easy addition of new automotive portals. Scraping more websites and increasing the dataset volume to hundreds of thousands of listings will significantly increase the mathematical precision of the predictive model.

## ⚠️ Limitations & Caveats
While this tool utilizes advanced statistical modeling, the second-hand car market is inherently subjective. **Please be aware of the following limitations:**

1. **Dataset Size:** While 15,000 - 20,000 listings provide a solid statistical baseline, it may not perfectly capture the nuances of extremely rare, vintage, or highly specific vehicle trims.
2. **Unquantifiable Parameters:** The algorithm calculates value based on macroscopic data (Make, Model, Year, Mileage, Engine Power, etc.). It **cannot** account for critical physical factors that drastically alter a car's price, such as:
   * Engine health and mechanical condition.
   * Scratches, dents, or paint quality.
   * Interior wear and tear (e.g., torn leather, smells).
   * Detailed maintenance history and timing belt replacements.
   * The urgency of the seller to liquidate the asset.

## 🚀 How to Run the Project Locally

### 1. Setup the Environment
Clone the repository and install the required dependencies:
```bash
git clone [https://github.com/RogerBrusau/car-price-mlops.git](https://github.com/RogerBrusau/car-price-mlops.git)
cd car-price-mlops
pip install -r requirements.txt
```

### 2. Launch the Streamlit Interface
To use the interactive price predictor:
```bash
cd NOUPROGRAMA
streamlit run app.py
```

### 3. (Optional) Retrain the Model

If you have executed the scraper to gather new data, you can retrain the model by running:
```bash
cd NOUPROGRAMA
python baseline_train.py --input ../used_car_dataset/data/gold/train_ocasionplus.parquet
```
